# AI-CLUB-RCC
Project: AI-Powered Movement Tracking System for Rehabilitation
Goal: Build a computer vision application that uses a standard webcam to track a person’s movements, analyze their range of motion, and give feedback during simulated rehabilitation exercises. Instead of expensive motion-capture equipment or wearable sensors, we use AI to identify body parts and track them over time.
Example: someone raises their arm from their side to shoulder height. The system will:
Identify the shoulder, elbow, and wrist
Track those joints as the person moves
Calculate approximate joint angles and range of motion
Count repetitions
Compare the movement to a predefined reference exercise
Identify deviations from the expected movement pattern
Display results on an interactive dashboard
Research question:
 “How do different machine learning and computer vision models compare in their accuracy, computational efficiency, and ability to recognize rehabilitation movements using low-cost webcam technology?”
Possible title:
 “Evaluating Computer Vision and Machine Learning Models for Low-Cost Rehabilitation Movement Tracking: Accuracy, Latency, and Computational Efficiency"
